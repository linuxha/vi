# FLEX2 SHORT PROGRAMMING GUIDE

How to use file open /read /write in FLEX2 OS.

## Part 1
```asm
* Important addresses:
* DOS:
WARMS EQU $AD03 * Warm start
INCH EQU $AD09 * INCH
OUTCH EQU $AD0F * OUTCH
GETCHR EQU $AD15 * get character from terminal -> A
PUTCHR EQU $AD18 * put character to terminal <- A
PSTRNG EQU $AD1E * print string X = address of string ,
 * end with $04
PRCLF EQU $AD24 * print CR LF
NXTCH EQU $AD27 * get next character from line
 * buffer -> A (=$0D end)
GETFIL EQU $AD2D * get file spec, X=#FCB
SETEXT EQU $AD33 * Set extension
 * (0=BIN,1=TXT,2=CMD,3=BAS,7=DAT) <-A
OUTDEC EQU $AD39 * X=ADDRESS(!) of 16bit binary (LDX #XSAVE)
OUTHEX EQU $AD3C * X=ADDRESS(!) of 8 bit binary
OUTADR EQU $AD45 * X=ADDRESS(!) of 16bit binary
RPTERR EQU $AD3F * X=#FCB reports error
GETHEX EQU $AD42 * -> X
INDEC EQU $AD48 * -> X
FMS:
FMSCLS EQU $B403 * FILE MANAGEMENT SYSTEM CLOSE
FMS EQU $B406 * FILE MANAGEMENT SYSTEM ENTRY
```

## Part 2

### Open Text file for READ

```asm
ADRFCB RMB 320 *  reserve memory for file I/O

OFILE LDX #ADRFCB *  POINT TO FCB
 JSR GETFIL *  GET FILE SPEC
 BCS FERROR *  ANY ERRORS?
 LDAA #1 *  SET UP CODE FOR OPEN
 STAA 0,X *  PLACE IT FOR READ OPEN
 JSR SETEXT *  SET 1 FOR TXT EXTENSION
 JSR FMS *  CALL FMS - DO OPEN
 BNE FERROR *  CHECK FOR ERROR
 LDX #ADRFCB *  POINT TO FCB
 CLRA *  SET A=0 FOR TXT READ WITH COMPRESSION
 STAA 59,X *  SET FOR TXT
 BRA OKFILE *  No error
* READING AND FILE ERROR HANDLING SEE BINARY PART
```

### open Bin file

```asm
ADRFCB RMB 320 *  reserve memory for file I/O
XSAVE RMB 2
XPOINTR EQU $6000 *  EXAMPLE FOR DATA STORE
OFILE LDX #ADRFCB *  POINT TO FCB
 JSR GETFIL *  GET FILE SPEC
 BCS FERROR *  ANY ERRORS?
 LDAA #1 *  SET UP CODE FOR OPEN
 STAA 0,X *  PLACE IT FOR READ OPEN
 CLRA *  SET A TO 0 = BIN
 JSR SETEXT *  SET BIN EXTENSION
 JSR FMS *  CALL FMS - DO OPEN
 BNE FERROR *  CHECK FOR ERROR
 LDX #ADRFCB *  POINT TO FCB
 LDAA #$FF
 STAA 59,X *  SET FOR BINARY READING
 BRA OKFILE *  No error
FERROR JSR RPTERR *  REPORT ERROR
 JSR FMSCLS *  CLOSE ALL FILES
 LDX #MESFERR *  LOAD MESSAGE ADDRESS FOR ERROR
 JSR PSTRNG *  AND PRINT IT
 JMP WARMS *  RETURN TO FLEX
MESFERR FCB 13,10
 FCC "FILE OPEN ERROR"
 FCB 13,10,04
OKFILE JMP MAIN *  now do your programm
*
* example how to process read and check for errors
*
MAIN LDX #XPOINTR *  WHERE TO STORE DATA
 STX XSAVE
BINLOOP LDX #ADRFCB *  POINT TO FCB
 JSR FMS *  CALL FMS - GET BINARY VALUE
 BNE EFILE *  ERRORS? break condition of loop
 LDX XSAVE
 STAA 0,X *  DATA IS IN A
 INX
 STX XSAVE
 CPX #7FFF *  END Memory range? Make this as parameter !
 BEQ EFILE2 *  REPORT as another error and break all
 BRA BINLOOP *  Do more until end of file
FLEX2 Short Programming Guide 4
* GET ERROR STATUS
*
EFILE LDAA 1,X *  GET ERROR TYPE
 CMPA #8 *  IS IT EOF ERROR?
 BNE EFILE2 *  put error message for something went wrong
 LDAA #4 *  CLOSE FILE CODE
 STAA 0,X *  STORE IN FCB
 JSR FMS *  CALL FMS - CLOSE FILE
 JMP WARMS *  RETURN TO FLEX OR CONTINUE WITH MAIN !
*
* REPORT READ ERROR
*
EFILE2 JSR FMSCLS *  CLOSE ALL FILES
 LDX #MESERR2 *  Message for ERROR 2
 JSR PSTRNG
 JMP WARMS *  RETURN TO FLEX
MESERR2 FCB 13,10
 FCC "ERROR DURING READ"
 FCB 13,10,04
```

## Writing

```asm
* All the same, only use the following opening
OFILE LDX #ADRFCB *  POINT TO FCB
 JSR GETFIL *  GET FILE SPEC
 BCS FERROR *  ANY ERRORS?
 LDAA #2 *  SET UP CODE FOR OPEN WRITE
 STAA 0,X *  PLACE IT FOR READ OPEN
 CLRA *  SET A TO 0 = BIN
 JSR SETEXT *  SET BIN EXTENSION
 JSR FMS *  CALL FMS - DO OPEN
 BNE FERROR *  CHECK FOR ERROR
 LDAA #$FF *  SET A=$FF FOR BIN WRITE
 STAA 59,X *  SET FOR BIN
*
* WRITE DATA DO THE FOLLOWING
*
 LDX #ADRFCB *  POINT TO FCB
 LDAA DATA *  GET DATA TO WRITE
 JSR FMS *  DO IT
 BNE FERROR * BRANCH TO ERROR ROUTINE
 BRA CONTINUE * ELSE CONTINUE NORMAL
```
